# Remodelaciones FVJ - Frontend

Frontend del sistema de gestión de Remodelaciones FVJ (agenda, presupuestos, órdenes, facturas, compra de materiales y clientes).

## Correr en local

**Requisitos:** Node.js

1. Instalar dependencias:
   `npm install`
2. Iniciar el servidor de desarrollo:
   `npm run dev`
